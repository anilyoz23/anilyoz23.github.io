01EKLENTİ

Caveman

Claude kısa konuşur

Claude'u mağara adamı gibi konuşturuyor: "Harika soru, hemen bakıyorum" gibi laflar gidiyor, kod aynen kalıyor. Geliştiricinin örneğinde aynı cevap 63 token'dan 20 token'a iniyor.

TERMİNALclaude plugin marketplace add JuliusBrussee/caveman && claude plugin install caveman@caveman
YA DA CLAUDE CODE'UN İÇİNDE · ÖNCE/plugin marketplace add JuliusBrussee/caveman
SONRA/plugin install caveman@caveman

Gereken: Node.js 18 ya da üstü. Kapatmak için Claude'a "stop caveman" yaz.

JuliusBrussee/cavemanGitHub ↗
02PROGRAM

RTK

Terminal çıktısını özetler

Claude terminalde bir komut çalıştırınca bazen 40 satır çıktı okuyor; RTK bunu 3 satıra indiriyor. Geliştiricisi yaygın komutlarda %60–90 tasarruf diyor. Bu oran komut çıktısı için; toplam limitin aynı oranda azalmaz.

1 · MACbrew install rtk
1 · WINDOWSwinget install rtk-ai.rtk
1 · LINUXcurl -fsSL https://raw.githubusercontent.com/rtk-ai/rtk/refs/heads/master/install.sh | sh
2 · HEPSİNDE: CLAUDE CODE'A BAĞLArtk init -g

Gereken: Mac'te Homebrew, Windows'ta winget. Aynı isimde başka bir program var; rtk gain yazınca tasarruf tablosu geliyorsa doğrusunu kurdun.

03EKLENTİ

Context-mode

Logları sohbete dökmek yerine kenara, bir kutuya kaldırıyor. Claude'a bir şey lazım olunca kutunun içinde arıyor, gerisini boş yere sırtında taşımıyor.

TERMİNALclaude plugin marketplace add mksglu/context-mode claude plugin install context-mode@context-mode

Gereken: Node.js 24.15 ya da üstü. Windows'ta ayrıca Git for Windows.

Claude Code'da limitimi daha az harcamak için şu dört aracı resmi kaynaklarından kur:
1. Caveman (github.com/JuliusBrussee/caveman): claude plugin marketplace add JuliusBrussee/caveman && claude plugin install caveman@caveman
2. RTK (github.com/rtk-ai/rtk): Mac'te brew install rtk, Windows'ta winget install rtk-ai.rtk, Linux'ta README'deki kurulum komutu. "rtk gain" çalışıyorsa doğru araçtır; sonra rtk init -g. Telemetri ya da proxy sorarsa hayır de.
3. Context-mode (github.com/mksglu/context-mode): claude plugin marketplace add mksglu/context-mode, sonra claude plugin install context-mode@context-mode
4. Graphify (github.com/Graphify-Labs/graphify): uv tool install graphifyy, sonra graphify install
Kurallar: İşletim sistemimi kendin anla, önce kurulu olanları kontrol et ve onları atla. Kurmadan önce aracın README'sine bak; komut değişmişse README'dekini göster. Her adımdan önce çalıştıracağın komutu ve ne değiştireceğini bir cümleyle söyle, onayımı bekle. Node, Python ya da uv eksikse kurmadan önce sor. Bir araç kurulamazsa zorlama: atla, nedenini söyle, sıradakine geç. Bunların dışında hiçbir şey kurma.
